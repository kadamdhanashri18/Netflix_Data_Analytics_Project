# Netflix_Data_Analytics_Project

# 📊 Project Overview

This is an end-to-end Netflix Data Analytics project developed using Excel, Python, MySQL and Power BI.

The project starts with an unclean customer viewing and subscription dataset. The data is cleaned and transformed using Python, analyzed using SQL, and finally presented through an interactive Power BI dashboard.
